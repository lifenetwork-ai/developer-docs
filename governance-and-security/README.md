# Governance & security overview

- The LIFE ERC20 token has no owner or admin role, so no key or multisig can mint, pause, blacklist or upgrade the token.
- Administrative keys control only the token distribution contracts and the LIFE AI chain administration. See [Admin keys & multisig](admin-keys-and-multisig.md).
- Vesting vault upgrades can only execute through an on-chain timelock with a minimum 48-hour delay.
- Protocol-level cryptography and audits: [Cryptography & audits](../life-chain/cryptography-and-audits.md).
