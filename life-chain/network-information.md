## Add the testnet to MetaMask

1. Open MetaMask → **Networks** → **Add network** → **Add a network manually**.
2. Enter the values from the table above (Network name, RPC URL, Chain ID `99991`, Currency symbol `ALIFE`, Block explorer URL).
3. Save and switch to the network.
